# ULSOO CI — 브랜드 아이덴티티 규정

> 작성일: 2026-08-08
> 적용 범위: ULSOO 과제의 모든 대외 산출물 — 웹사이트, 발표자료, 보고서 표지, 전시 패널, 배너
> 관련 문서: [[STYLE_REF_MeokHanji]] (화면 스타일), [[DESIGN]] (구현 단일 원천)
> 자산 위치: `assets/ci/`

이 문서는 **로고를 어떻게 쓰는가**를 규정한다. 화면 배색·타이포그래피 전반은
[[STYLE_REF_MeokHanji]]가 원천이며, 두 문서가 충돌하면 로고에 관한 한 이 문서가 우선한다.

---

## 1. 구성요소

CI는 세 요소로 이루어지고, 셋을 조합한 것이 **시그니처**다.

| 요소 | 정의 | 파일 |
|------|------|------|
| **심볼** | 오방색 붓획 마크. 얼쑤의 흥과 문화유산의 결을 붓질로 표현한 기존 마크를 그대로 승계 | [[ulsoo-symbol.svg]] |
| **워드마크** | "ULSOO"를 모필(붓글씨)로 쓴 로고타입. **아웃라인 처리되어 폰트 설치가 필요 없다** | [[ulsoo-wordmark.svg]] |
| **부제** | Ultimate Sophisticated Object Technology. 시그니처에 포함하지 않고 필요 시 별도 조판 | — |

### 워드마크 제작 방식 (2026-08-08 확정)

East Sea Dokdo 서체로 조판한 "ULSOO"의 글리프 윤곽을 **패스로 변환(아웃라인)**해 고정했다.
따라서 어느 환경에서도 동일하게 재현되며, 서체가 갱신돼도 워드마크는 변하지 않는다.

- 자간: 0.01em (사이트 표기와 동일)
- 잉크 바운딩 박스: 1789 × 470 units (unitsPerEm 1000)
- **워드마크를 폰트로 다시 조판하지 않는다.** 반드시 이 SVG를 쓴다

## 2. 시그니처

| 조합 | 비율 | 용도 | 파일 |
|------|------|------|------|
| **가로형** | 719 × 210 | 기본. 헤더·문서 머리말·배너 등 가로 공간 | [[ulsoo-signature-horizontal.svg]] |
| **세로형** | 276 × 329 | 정방형에 가까운 공간. 표지·포스터·굿즈 | [[ulsoo-signature-vertical.svg]] |
| **심볼 단독** | 240 × 210 | 파비콘, 앱 아이콘, 이미 ULSOO임이 명확한 맥락 | [[ulsoo-symbol.svg]] |
| **워드마크 단독** | 1789 × 470 | 심볼을 쓸 수 없는 좁고 긴 공간 | [[ulsoo-wordmark.svg]] |

**조합 규격 (임의 변경 금지)**

- 가로형: 워드마크 높이 = 심볼 높이 × 0.52, 심볼과 워드마크 간격 = 심볼 높이 × 0.30, 세로 중앙 정렬
- 세로형: 워드마크 폭 = 심볼 폭 × 1.15, 상하 간격 = 심볼 높이 × 0.22, 가로 중앙 정렬

## 3. 색상

### 심볼 — 오방색 (유일한 채도 예외)

| 색 | 값 |
|----|-----|
| 청 (navy) | `#173d7a` |
| 적 (red) | `#9a2b24` |
| 주 (coral) | `#e45f42` |
| 청록 (teal) | `#249aa4` |
| 금 (gold) | `#d6a452` |

**UI 팔레트는 먹·한지 무채색에 금 하나만 허용하지만, 심볼은 브랜드 아이덴티티로서 예외다.**
UI에서 은퇴한 teal·red·coral은 심볼 안에서만 생존한다 ([[STYLE_REF_MeokHanji]] Logo Mark 참조).

### 단색 버전

인쇄 1도, 각인, 팩스, 저해상도 등 오방색을 쓸 수 없을 때만 사용한다.

| 버전 | 색 | 파일 |
|------|-----|------|
| 먹 단색 | `#171310` | [[ulsoo-symbol-mono-meok.svg]] |
| 설백 단색 | `#f7f3ea` | [[ulsoo-symbol-mono-white.svg]] |

### 워드마크

기본 먹 `#171310`. 어두운 배경에서는 설백 `#f7f3ea`. **그 외의 색은 쓰지 않는다.**

## 4. 최소 크기 (2026-08-08 화면 실측)

축소 시안을 1:1로 렌더해 눈으로 확인한 값이다. 계산값이 아니다.

| 자산 | 최소 | 실측 소견 |
|------|------|-----------|
| 심볼 (오방색) | **32px** | 16px에서 획이 완전히 뭉개짐, 24px도 경계선. 32px부터 붓획이 분리되어 읽힘 |
| 가로 시그니처 | **120px** | 90px에서 심볼이 뭉개짐(워드마크는 읽힘). 120px부터 양쪽 모두 성립 |
| 세로 시그니처 | **80px** | 60px에서 심볼 붕괴. 80px부터 성립 |
| 워드마크 단독 | **60px** | 붓획 특성상 심볼보다 축소에 강함 |

**32px 미만에서는 심볼 대신 [[favicon.svg]](획을 단순화한 소형 전용판)를 쓴다.** 실측 결과
파비콘판은 16px에서도 형태가 유지된다. 두 파일은 용도가 다르며 서로 대체하지 않는다.

---

## 5. 보호 여백 (clear space)

**사방 여백 = 심볼 높이 × 0.25.** 이 영역 안에는 텍스트·이미지·괘선 등 어떤 요소도 넣지 않으며,
지면 가장자리와의 거리도 이 값 이상을 확보한다.

가로 시그니처를 104px 높이로 쓴다면 심볼 높이가 104px이므로 여백은 26px이다.

## 6. 배경별 운용

| 배경 | 사용 |
|------|------|
| 한지 `#e7e0d2` · 백자 `#f2ede2` | 오방색 심볼 + 먹 워드마크 (기본) |
| 먹 `#171310` | 오방색 심볼 + 설백 워드마크. 심볼은 어두운 배경에서도 오방색을 유지한다 |
| 사진 위 | 명도가 균일하고 충분히 밝거나 어두운 영역에만. 복잡한 부분에는 올리지 않는다 |
| 채도 높은 유색 배경 | **금지** — 오방색이 배경색과 충돌한다 |

## 7. 금지 사례

- 가로세로 비율 왜곡 (한 축만 늘이거나 줄이기)
- 색 변경 — 오방색 5색의 임의 교체, 그러데이션 적용
- 그림자·외곽선·글로우 등 효과 추가 (시스템은 완전히 플랫하다)
- 회전, 기울이기
- 심볼과 워드마크의 간격·크기 비율 임의 조정, 상하좌우 재배치
- 워드마크를 폰트로 다시 조판 (아웃라인 SVG를 쓸 것)
- 최소 크기 미만 사용
- 저대비 배경 위 배치
- 심볼을 다른 그래픽 요소와 합성하거나 프레임 안에 가두기

## 8. 파일 목록

```
assets/ci/
├─ ulsoo-symbol.svg               심볼 (오방색, 기본)
├─ ulsoo-symbol-mono-meok.svg     심볼 먹 단색
├─ ulsoo-symbol-mono-white.svg    심볼 설백 단색
├─ ulsoo-wordmark.svg             워드마크 (아웃라인)
├─ ulsoo-signature-horizontal.svg 시그니처 가로형
├─ ulsoo-signature-vertical.svg   시그니처 세로형
└─ preview.html                   검수 시트 (조합·최소 크기·여백·금지 사례)
assets/favicon.svg                소형 전용판 (32px 미만)
```

### 파일 형식에 대하여

**마스터는 SVG다.** 벡터이므로 어떤 크기에서도 깨지지 않고, 파일 하나로 인쇄까지 대응한다.
PowerPoint·Word(Office 2016 이상)와 한글은 SVG 삽입을 지원하므로 별도 변환 없이 그대로 쓴다.

PNG가 필요한 도구를 만나면 SVG를 미리보기(Preview)나 Figma에서 원하는 크기로 내보낸다.
**저장소에 흰 배경이 구워진 PNG를 두지 않는다** — 한지·먹 배경 위에 얹을 수 없기 때문이다
(macOS `qlmanage` 변환본이 이 문제를 일으켜 폐기했다, 2026-08-08).

## 9. 미해결

| 항목 | 상태 |
|------|------|
| 심볼의 조형 근거(어떤 형상을 붓획으로 옮긴 것인지) 문서화 | 제작 경위를 아는 분의 설명 필요 |
| 영문 표기 시 부제 조판 규격 | 미정 — 현재는 사이트 헤더 관례(Pretendard 10px, 자간 0.06em)를 따름 |
| 국문 로고타입("얼쑤") 제작 여부 | 미정 |
| 투명 배경 PNG 세트 | 필요 시 브라우저 캔버스 경로로 생성 가능 |
