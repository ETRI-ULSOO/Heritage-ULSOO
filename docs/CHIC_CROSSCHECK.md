## D. 역방향 지적 — CHIC 사이트 쪽 확인 요망

대조 과정에서 발견한, **CHIC 사이트에 게시 중인 이미지의 문제**다. 본 사이트가 아니라
`chic-site` 저장소의 사안이므로 별도 처리가 필요하다.

1. **`results/knowledge-graph.webp` — 개인 북마크 노출**
   브라우저 창을 통째로 캡처한 이미지로, 북마크바에 내부 자산명이 그대로 읽힌다:
   `CHCS_SQI`, `웹 조각 갤러리`, `HEEKWON_NAS`, `CHIC-Data - Synolo…`, `ARCSP - Synology…`,
   `OnAR - Synology Di…`, `NewstormNas - Syn…`. 공개 사이트 게시물로는 부적절하다.

2. **같은 이미지의 출처 문제**
   해당 화면은 CHIC 산출물이 아니라 **영국박물관 'Museum of the World'**(Google Cultural
   Institute) 페이지다. 하단에 British Museum·Google Cultural Institute 로고가 찍혀 있다.
   벤치마크 참고 화면을 성과 이미지 위치에 쓰고 있다면 캡션 명시 또는 교체가 필요하다.

3. **`results/nl-search.webp` — 경미**
   주소창에 내부 S3 엔드포인트(`chcs-curator-frontend-2022.s3-website.ap-northeast-2…`)와
   우상단 사용자 프로필 사진이 함께 노출된다. 크롭 권장.

### A-3 재판정 (2026-08-05)

최초 대조 때는 "F1 89.0%의 근거를 찾지 못했다"고 보고했으나, 본 사이트 `techFields`를 다시 읽어
판정을 수정한다. 해당 항목에 **"문화유산 속성 분류체계(대분류 10종·세분류 92종)와 169,899문장"**
이라는 상세 서술이 이미 있고, 이 "92종"은 CHIC 최종보고서의 "데이터 속성 92종"과 정확히 일치한다.
즉 본 사이트의 언어지능 수치는 보고서에서 온 것이며 F1 89.0%도 같은 계열의 실측값으로 보는 것이
타당하다. 실제 오류는 수치가 아니라 **COLING 2022 논문을 "언어모델"로 지칭한 부분**이었다
(해당 논문은 개체명 태스크용 코퍼스 KOCHET). 따라서 수치는 보존하고 논문 정체만 바로잡았다.

### C 반영 상세 — 로봇팔 카드

"사진으로 보여줄 수 있는 것" 방침의 직접 적용 사례다. 해당 성과는 이미 `techFields`에 문장으로
존재했으나 **사진이 없었다.** `chic-site`의 실사 사진(로봇팔·턴테이블·유물 촬영 현장)을 16:9로
가공해 실증사례 7번째 카드로 추가했다.

- 이미지: `assets/img/case-robotarm.webp` (1200×675, 원본 1183×861 중앙 크롭 — 상단의 인물 다리가 크롭으로 제외됨)
- 문안 근거: "국내 최초·최고 3m"는 본 사이트 기존 techFields 서술, "촬영자 숙련도에 따른 품질 차이"는 CHIC 결과물 목록 원문
- 레이아웃 영향: 실증사례가 6 → 7장이 되어 데스크톱 3열 그리드에서 마지막 행에 1장만 남는다(3+3+1). 카드 폭은 균일하게 유지되며 모바일 1열·태블릿 2열은 영향 없음
